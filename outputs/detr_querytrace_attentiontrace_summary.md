# DETR Decoder Query Mapping and Cross-Attention Analysis

## Objective

The Multimodal Decoder experiments established that text prompts modify fusion-memory representations and that these prompt-conditioned representations become increasingly important in deeper fusion layers.

The next objective was to understand how the DETR decoder consumes these fusion representations to generate the final segmentation mask.

Specifically, the following questions were investigated:

1. Which DETR decoder query produces the final selected mask?
2. Which fusion-memory tokens are read by that query?
3. How does the decoder connect fusion-memory representations to the final segmentation output?

This analysis focuses on:

```text
transformer.decoder.layers.0–5
```

rather than the Multimodal Decoder:

```text
transformer.encoder.layers.0–5
```

---

# Experiment 1: DETR Decoder Query Mapping

## Method

The final selected mask was used as the backward target:

```text
target = mean(masks_logits[0, target_mask_index])
```

Gradients were backpropagated into the DETR decoder output tensor:

```text
hs
```

captured from:

```text
self.transformer.decoder(...)
```

The decoder output had shape:

```text
(6, 1, 200, 256)
```

corresponding to:

```text
6 decoder layers
1 image
200 object queries
256 feature channels
```

For every query index q, a gradient score was computed:

```text
query_score(q) = || d(target) / d(hs_q) ||
```

The responsible query was defined as:

```text
q* = argmax query_score(q)
```

---

## Results

| Image | Prompt | Target Mask Index | Responsible Query |
|----------|----------|----------|----------|
| School Bus | yellow school bus | 0 | 144 |
| Cat | cat | 0 | 144 |
| Dog | dog | 0 | 144 |

This query mapping was run independently for all three images.

For the school bus example:

```text
query 144
l2_grad = 5.71e-03
normalized = 1.00
```

For the cat example:

```text
query 144
l2_grad = 1.02e-03
normalized = 1.00
```

For the dog example:

```text
query 144
l2_grad = 1.69e-03
normalized = 1.00
```

The other displayed queries had near-zero gradients.

---

## Interpretation

The final mask is not generated by decoder query 0.

Instead, the final selected mask consistently originates from:

```text
query 144
```

across all tested examples.

This means that all subsequent decoder analysis should focus on:

```text
q* = 144
```

rather than assuming that mask index 0 corresponds directly to query index 0.

This establishes the decoder query responsible for the final segmentation output in the tested images.

Important note:

```text
This does not prove query 144 is always responsible for every image or prompt.
It shows that query 144 was responsible for the selected final mask in the school bus, cat, and dog examples tested here.
```

# Experiment 2: DETR Decoder Cross-Attention Trace

## Method

After identifying the responsible query, decoder cross-attention was analyzed.

The following modules were traced:

```text
transformer.decoder.layers.0.cross_attn
transformer.decoder.layers.1.cross_attn
transformer.decoder.layers.2.cross_attn
transformer.decoder.layers.3.cross_attn
transformer.decoder.layers.4.cross_attn
transformer.decoder.layers.5.cross_attn
```

For each layer, the attention inputs were captured before output projection.

Observed shapes:

```text
Q = (1, 8, 201, 32)
K = (1, 8, 5184, 32)
V = (1, 8, 5184, 32)
```

Attention weights therefore had shape:

```text
(1, 8, 201, 5184)
```

The memory dimension:

```text
5184 = 72 × 72
```

corresponds exactly to the fusion-memory grid produced by the Multimodal Decoder.

The query dimension is 201 rather than 200 because the decoder includes an extra token along with the object queries, likely a presence token. Query 144 remains valid because it lies within the query dimension and was independently identified by gradient tracing.

Attention weights were recomputed using:

```text
softmax(QKᵀ / √d)
```

and averaged across heads.

For query 144, the resulting attention was reshaped into:

```text
72 × 72
```

spatial attention maps.

Outputs generated:

```text
decoder_layer_i_query144_attn.npy
decoder_layer_i_query144_attn.png
decoder_top_tokens.csv
```

# Cross-Example Analysis

A consistent pattern emerged across all tested examples.

Independent query tracing was performed for:

```text
School Bus
Cat
Dog
```

and all three produced:

```text
target_mask_index 0
↓
decoder query 144
```

| Image | Prompt | Responsible Query |
|----------|----------|----------|
| School Bus | yellow school bus | 144 |
| Cat | cat | 144 |
| Dog | dog | 144 |

Although the responsible query remained identical, the spatial memory region attended by query 144 varied substantially across images.

| Image | Dominant Region |
|----------|----------|
| School Bus | row 35–45, col 51–56 |
| Cat | row 35–38, col 55 |
| Dog | row 48–50, col 52–53 |

This indicates that query 144 is not tied to a fixed spatial location.

Instead, query 144 behaves as a learned object query that dynamically reads different regions of the fusion-memory grid depending on image content.

The decoder therefore appears to reuse the same object-query slot while adapting its spatial attention to different objects.

# Overall Interpretation

The DETR decoder experiments establish the second half of the prompt-to-mask pathway.

The earlier Multimodal Decoder experiments showed:

```text
Prompt
↓
Fusion-memory representations
```

The DETR decoder experiments show:

```text
Fusion-memory representations
↓
Decoder query 144
↓
Cross-attention to selected fusion-memory tokens
↓
Final segmentation mask
```

The key findings are:

1. The final selected mask is consistently produced by decoder query 144 across all tested examples.
2. Query 144 reads directly from the 72×72 fusion-memory grid produced by the Multimodal Decoder.
3. The specific memory tokens attended by query 144 depend on the image and object being segmented.
4. Query 144 acts as the decoder bridge between fusion-memory representations and final mask generation.
5. The same query can segment different object categories while attending to different regions of the fusion-memory grid.

Together, the Multimodal Decoder and DETR Decoder analyses provide the following pathway:

```text
Prompt
↓
Prompt modifies fusion-memory representations
↓
Prompt-conditioned fusion tokens
↓
Decoder query 144
↓
Cross-attention over selected fusion-memory tokens
↓
Final segmentation mask
```

At this stage, the DETR decoder analysis establishes:

```text
Which query produces the final mask?
→ Query 144

Which fusion-memory tokens are read?
→ Image-dependent subset of the 72×72 fusion grid

How does the decoder connect fusion memory to the mask?
→ Through query 144 cross-attention
```

The DETR decoder experiments therefore identify the mechanism by which fusion-memory representations are consumed to generate the final segmentation output.

Importantly, this decoder analysis alone does not prove that the attended fusion tokens are exactly the same tokens modified by the prompt. It establishes the readout pathway from fusion memory to mask generation.

The subsequent pathway-consistency and causal-ablation experiments answer the next question:

```text
Are the prompt-conditioned fusion tokens
actually used by query 144,
and do they causally contribute
to the final mask?
```

Those experiments complete the prompt-to-mask analysis by linking Multimodal Decoder representations to DETR decoder readout and final segmentation behavior.
